# Homika Pro v1.0 — Production Smoke Test

Use the signed APK generated by the release workflow. This checklist is intentionally short and release-blocker focused.

## 1. Launch and core navigation

- App launches without crash.
- Home, Calendar, Bookings, Money and More open normally.
- Back navigation does not trap the user or exit unexpectedly from an intermediate screen.
- Bahasa Melayu / English switching works and persists.
- Appearance/text-size settings remain usable without hiding primary controls.

## 2. Booking flow

- Add or select a property.
- Tap an empty Calendar date and create a booking.
- Open the booking again from Calendar/Bookings.
- Edit and save the booking.
- Verify blocked/double-booking protection still behaves correctly.
- Verify payment/deposit information remains readable and consistent.

## 3. Trial and activation

On a suitable test state/device:

- Start Free opens the dedicated trial flow.
- Already Purchased opens Email + 6-digit PIN activation.
- Licence Key remains available as fallback from the paid activation flow.
- Invalid input shows a readable error and does not crash.
- Successful activation reaches the app normally.

Do not deliberately consume a real customer's trial or alter a production licence merely for cosmetic testing.

## 4. Purchase / renewal

- Buy/Renew opens the intended Homika store flow.
- Manual QR payment instructions are readable.
- Existing approved purchase activation remains Email + PIN first, Licence Key fallback second.
- Renewal preserves the intended existing-licence behavior.

Admin approval/rejection should only be exercised with a dedicated test purchase, not a real customer order.

## 5. Homika Cloud

- Homika Cloud screen opens without crash.
- Sync status renders correctly.
- `Sync now` completes or returns a clear actionable error.
- Automatic backup switch can be changed.
- `Back up now` works when account/licence/network prerequisites are satisfied.
- Cloud recovery page opens; restore is disabled or explained when no backup exists.
- Existing local backup/restore remains accessible.

## 6. Update path

- Current version/package is `com.homika.app`.
- Check Update does not crash.
- If a newer signed release exists, download/install flow reaches Android's expected install confirmation.
- Signature/package verification is not bypassed.

## 7. Final release acceptance

The release is acceptable when:

- no crash is found in the smoke path;
- no primary action is blocked;
- no data-loss behavior is observed;
- no activation/payment/cloud regression is reproduced;
- signed release build is green.

Minor spacing preferences, optional copy refinements and feature ideas are not v1.0 blockers and should move to post-release feedback.
