# Homika Pro v1.0

Homika Pro is a local-first homestay management app with commercial licensing and optional encrypted cloud protection.

## Included in v1.0

- Property management
- Calendar-based booking workflow
- Booking detail/edit/cancellation flows
- Money, payment, deposit and expense tracking
- Reports/analytics foundations
- App lock, appearance, language and text-size controls
- Bahasa Melayu and English
- Signed private APK updater
- 7-day self-service trial with one-device limit
- Paid licensing with three-device limit
- Purchase activation using email + 6-digit PIN
- Licence Key fallback/recovery activation
- Purchase, renewal and manual personal-QR payment flow
- Manual admin payment approval/rejection
- Customer/admin notification foundations
- Encrypted Homika Cloud Backup
- Multi-device snapshot sync
- Automatic backup and cloud recovery UX

## Release policy

v1.0 is feature-frozen after the 15B production audit and 15C release-candidate gate. New features should be driven by real user feedback rather than added during release stabilization.
